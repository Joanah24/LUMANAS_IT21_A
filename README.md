2. Why can't we create an object directly from an abstract class? What is the purpose of this restriction?
   -Kay incomplete ang abstract class.Kinahanglan ang child class mo provide sa implementation sa abstract methods.

3. If you need to add another child class to your polymorphism program, how would your existing code handle it?
-Magbuhat lang ko ug another child class nga mo extend sa parent clss ug mo override sa method.

4. Can polymorphism and abstraction work together in a single program? Explain how and provide an example.
   -Oo,pwede sila mag work together.Ang abstraction mo hide sa details,unya ang polymorphism gina allow ang different behaviors.

5. As a future programmer, when would you use polymorphism, and when would you use abstraction?
-Gamiton nako ang polymorphism para sa different behaviors,ug abstraction para e hide ang unnecessary details sa program.
